# Unsupervised Learning
The model learns from data **without** any target or output labels.

- No labels
- Finds hidden patterns on its own
- Example: Group customers by buying habits
- Goal: Discover natural clusters in data
- Algorithms:
  - K-Means
  - DBSCAN
  - PCA

## FLow
1. Collect data
2. Clean and prepare data
3. No target column available
4. Choose Unsupervised algorithm
5. Model find hidden patterns
6. Grouping/Pattern discovery
7. Business insights

## Types
- Clustering
  - Customer segmentation
  - Document grouping
  - Image compression
- Association
  - Market basket analysis
  - Netword co-watch patterns
  - Medical symtom combinations
- Dimensionality Reduction
  - Image compression
  - Noise removal
  - Feature visualization
